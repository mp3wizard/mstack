# Prompts worth copying

Each prompt states the need and the check for done. Replace the bracketed parts.

## Understand

```
/mstack:design-mode why do people drop at step 3 of signup on mobile? read the funnel data in [path] and walk the flow. don't change anything yet.
```

```
/mstack:design-mode how does the invite flow work today, and why was it built this way? cite the decision records or say there are none.
```

## Design

```
/mstack:design-mode finance users can't find last month's failed payments on the reports page. design a fix inside our design system in [path]. done means every state has a screenshot at 375 and 1280 and a handoff package.
```

```
/mstack:diverge three layouts for the onboarding checklist. one must reject the usual card grid. judge them on time to first task.
```

## Evaluate

```
/mstack:design-mode audit [url] against WCAG 2.2 AA. per-criterion evidence, computed contrast, and keyboard walk. report only.
```

```
/mstack:critique [figma link]. objectives: new admins invite a teammate in under a minute. rate every finding 0 to 4.
```

```
/mstack:design-mode prepare a usability test for the new checkout. five tasks, the script, and the SUS form. i'll run the sessions and send you the raw answers.
```

## Hand off and check

```
/mstack:design-mode compare the built settings page at [url] with the design in [figma link]. pixel diff and live inspection.
```

## Away and back

```
/mstack:design-mode redesign the account area across web and mobile. going to bed. keep a decision log, stop when every flow has a handoff package, and don't publish anything.
```

```
/mstack:design-mode pick up where the last session stopped on the reports filter. the resume note is in .mstack/reports-filter/.
```
